# sim_original.py 使い方説明書 (Usage)

## 1. 概要
`sim_original.py` は、特定のきずパラメータ（ピッチ、深さ、幅）を 1 組だけ指定して、弾性波動 FDTD シミュレーション（2次元）を実行するためのスタンドアロン型のオリジナルプログラムです。
GPU（CuPy）を用いた高速演算により、固体中の音波（P波・S波）の伝搬をシミュレートし、受信波形を生成します。

---

## 2. 物理パラメータの設定
スクリプト内部に以下の材料および構造パラメータが定義されています。
*   **物性値 (鋼を想定)**: 
    *   密度 $\rho = 7840$ kg/m$^3$
    *   ヤング率 $E = 206$ GPa
    *   剛性率 $G = 80$ GPa
    *   ポアソン比 $V = 0.27$
*   **波の速度**:
    *   縦波（P波）速度 $c_l \approx 5900$ m/s
    *   横波（S波）速度 $c_t \approx 3190$ m/s
*   **時間・空間ステップ**:
    *   グリッドサイズ $\Delta x = \Delta y = 1.0 \times 10^{-5}$ m ($10\ \mu m$)
    *   時間ステップ $\Delta t$：クーランの安定条件（Courant-Friedrichs-Lewy 条件）を満たすように自動調整されます。

---

## 3. FDTD の処理内容
1.  **自由境界条件の設定**:
    *   `isfree` 関数にて、きず（欠陥）を考慮した応力ゼロ条件のマスク行列を作成します。
2.  **入射パルスの設定**:
    *   中心周波数 $4.7$ MHz、波数 $2.5$ の正弦波にハン窓（Hanning Window）を乗じた垂直入射パルスを設定。
3.  **粒子速度・応力の更新ループ**:
    *   リープフロッグ法により、粒子速度（$U_x$, $U_y$）と応力（$T_1$, $T_3$, $T_5$）を時間ステップごとに交互に更新します。
    *   GPU（CuPy）の二次元スライス・アレイ操作により並列処理を行います。
4.  **受信信号の記録**:
    *   探触子の位置に対応するグリッドインデックス（`sy_l` 〜 `sy_r`）における受信応力の平均値を各時間ステップごとに `wave` 配列へ記録します。

---

## 4. 動作要件・依存ライブラリ
*   **ハードウェア**: NVIDIA GPU
*   **ライブラリ**: `numpy`, `cupy`

---

## 5. 使用方法

### パラメータの編集
スクリプト内の以下の部分をテキストエディタ等で直接変更して、任意のきず寸法を指定します。
```python
# 傷の幅 m
f_width = 0.25e-3  # m (0.25 mm)
# 傷の間隔 m
f_pitch = 2.00e-3  # m (2.00 mm)
# 傷の深さ m
f_depth = 0.20e-3  # m (0.20 mm)
```

### 実行
```powershell
python vscode/simulation/sim_original.py
```
*(※シミュレーションはGPU上で実行され、進捗率が端末に表示されます。)*
