# 3D 超音波シミュレーション使用説明書 (UT_FlawVariation_Sim_3d.py)

このドキュメントでは、2D 版シミュレーション (`UT_FlawVariation_Sim.py`) を 3D に拡張したスクリプトの仕様と使用方法について解説します。

---

## 1. 概要
3D シミュレーションは、厚さ方向 ($Z$ 軸) を持つ弾性体の波動伝搬を計算します。これにより、2D では表現できなかった「有限な長さの欠陥」や「円形の探触子（点音源）」による回折、散乱現象をより正確に再現できます。

## 2. 2D 版との主な違い

| 項目 | 2D 版 (`UT_FlawVariation_Sim.py`) | 3D 版 (`UT_FlawVariation_Sim_3d.py`) |
| :--- | :--- | :--- |
| **計算次元** | $X, Y$ | $X, Y, Z$ |
| **応力成分** | $T_{xx}, T_{yy}, T_{xy}$ (3成分) | $T_{xx}, T_{yy}, T_{zz}, T_{xy}, T_{yz}, T_{zx}$ (6成分) |
| **粒子速度** | $V_x, V_y$ (2成分) | $V_x, V_y, V_z$ (3成分) |
| **音源形状** | 線音源 (直径相当の幅) | 円形音源 (直径相当の円盤) |
| **欠陥形状** | $Z$ 方向に無限に続く溝 | $Z$ 方向の長さを指定可能な溝 |
| **計算負荷** | 非常に軽量 | **非常に重い** (GPU メモリと計算時間を要する) |

## 3. 主要な関数

### `isfree_3d(...)`
- シミュレーション領域内の固体部分 (1) と真空部分 (0) を定義します。
- $Z$ 方向の中央に、長さ `f_length` の欠陥（溝）を配置します。

### `around_free_3d(...)`
- 境界条件（自由境界）の計算に使用します。
- 粒子速度ノードの周囲 6 つの応力ノードのうち、いくつが「真空」であるかをカウントします（Free Count 法）。
- $6.0 / (6.0 - count)$ の係数で粒子速度の更新式を補正します。

### `run_simulation_3d(f_width, f_pitch, f_depth, f_length=None)`
- メインの計算ループを実行します。
- 計算結果（探触子位置の平均 $T_{xx}$）を CSV として `tmp_output/sim_3d/` に保存します。

## 4. パラメータ設定の注意点

### メッシュサイズ (`mesh_length`)
- 3D では計算セル数が $N^3$ のオーダーで増えるため、メモリ消費が激しくなります。
- デフォルトでは `2.0e-5` (20μm) に設定されています。
- より詳細な解析が必要な場合は `1.0e-5` (10μm) に下げますが、GPU メモリ (VRAM) 24GB 以上を推奨します。

### 時間ステップ (`dt`)
- 安定条件に基づき $dx / cl / \sqrt{6}$ で自動計算されます。メッシュを細かくすると `dt` も小さくなり、必要なステップ数 (`t_max`) が増えます。

### 精度の型 (`float32`)
- メモリ節約のため、配列は `cp.float32` で宣言しています。

## 5. 実行方法
スクリプトを直接実行すると、デフォルトのパラメータでテストシミュレーションが走ります。

```powershell
python vscode/simulation/UT_FlawVariation_Sim_3d.py
```

ループ実行やパラメータスイープを行いたい場合は、`loop_UT_sim.py` のようなラッパースクリプトを 3D 版用に作成して呼び出すことを推奨します。
