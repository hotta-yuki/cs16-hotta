# plot.py 使い方説明書 (Usage)

## 1. 概要
`plot.py` は、特定の実験パターン（例: 試験体 patC の実験データ群）に対して、個別の CSV データを読み込んで全体の平均時間領域波形、および個々の測定スペクトルとそれらの平均スペクトルをプロット・保存するための実験データ解析用スクリプトです。

---

## 2. 主な機能
1.  **実験データの読み込みと前処理**:
    *   `vscode/simulation/data/patC_csv/scope_*.csv` から複数の測定波形データをロードします。
    *   日本語（SHIFT-JIS）や UTF-8 等のエンコーディング自動回避処理を施しています。
    *   最頻値（Mode）を算出し、バイアスオフセットを除去します。
    *   データが非常に長い場合を考慮し、先頭から $6000$ インデックスの範囲でカットして均一化します。
2.  **平均波形（時間領域）のプロット**:
    *   全ファイルの波形の平均値を求め、綺麗な「平均時間波形（patC）」として黒色の実線でプロットし画像保存します。
3.  **FFT スペクトル（個別・平均）のプロット**:
    *   各測定波形に対して `sourse_new_2.py` の `kiritori2` と `make_fftdata` を適用し、それぞれの振幅スペクトルを計算します。
    *   個別のスペクトルを薄い半透明の色（alpha=0.3）で、全体の平均スペクトルを黒い太線で重ねてプロットし、測定値のばらつきと全体の傾向を同時に可視化します。

---

## 3. 動作要件・依存ライブラリ
*   **環境**: Python 3.x
*   **ライブラリ**: `numpy`, `pandas`, `matplotlib`, `japanize_matplotlib` (グラフへの日本語対応用)
*   **依存関係**: 共通ライブラリ `vscode/simulation/sourse_new_2.py`

---

## 4. 使用方法
以下のコマンドで実行します。
```powershell
python vscode/simulation/plot.py
```

---

## 5. 入出力ファイル
*   **入力**: `vscode/simulation/data/patC_csv/*.csv` (実験波形データ)
*   **出力**:
    *   平均時間領域波形プロット: `tmp_output/exp_waveform_patC.png`
    *   個別＋平均 FFT スペクトルプロット ($2.0$ 〜 $8.0$ MHz): `tmp_output/exp_fft_individual_patC.png`
