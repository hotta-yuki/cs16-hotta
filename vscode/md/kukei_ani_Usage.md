# kukei_ani.py 使い方説明書 (Usage)

## 1. 概要
`kukei_ani.py` は、矩形溝（Kukei Groove）を有する試験体に対する 2次元弾性波動 FDTD法シミュレーションを実行し、その波面（応力・圧力分布）の伝搬の様子をアニメーションデータとして生成、あるいは GUI（Tkinter）を用いてリアルタイムにプレビューするためのスクリプトです。
出力されるアニメーションデータ（`.npz`）は、別途用意されたアニメーションプレイヤー等で再生できます。

---

## 2. 主な機能
1.  **FDTD弾性波動解析**:
    *   固体中の縦波（P波）および横波（S波）の伝搬挙動を、CuPy（GPU計算）を用いて高速に解析します。
    *   周期的粗面におけるきず（欠陥）での散乱や、縦・横波の**モード変換 (Mode Conversion)**を計算します。
2.  **アニメーション用 NPZ の保存**:
    *   シミュレーション全体の時間ステップのうち、間引きされたステップごとの応力分布（全体領域およびきず周辺の拡大領域）をデータファイル（`.npz`）に保存します。
3.  **Tkinter GUI プレビュー (オプション)**:
    *   GUI を立ち上げ、パラメータ（ピッチ、深さ、幅）を設定してその場でシミュレーションを実行し、アニメーションの伝搬挙動を視覚的にプレビューできます。

---

## 3. 動作要件・依存ライブラリ
*   **ハードウェア**: NVIDIA製 GPU 推奨（CuPyを使用するため）
*   **ライブラリ**: `numpy`, `cupy`, `matplotlib`, `tkinter`

---

## 4. コマンドライン引数 (Parameters)
本スクリプトは CLI（コマンドライン）から様々なパラメータを指定して実行可能です。

| 引数 | 型 | デフォルト値 | 説明 |
| :--- | :---: | :---: | :--- |
| `--pitch-mm` | float | `1.25` | きずのピッチ（間隔） [mm] |
| `--depth-mm` | float | `0.10` | きずの深さ [mm] |
| `--width-mm` | float | `0.25` | きずの幅 [mm] |
| `--probe-width-mm`| float | `7.0` | 探触子（音源）の直径 [mm] |
| `--output-dir` | str | *(所定パス)* | アニメーションデータの保存先フォルダ |
| `--save-interval` | int | `10` | データを保存する時間ステップの間隔（間引き度） |
| `--global-downsample`| int| `6` | 空間グリッドの間引き間隔（データ圧縮用） |
| `--zoom-width-mm` | float | `3.0` | きず拡大表示（ROI）の横幅 [mm] |
| `--zoom-height-mm`| float | `0.5` | きず拡大表示（ROI）の縦幅 [mm] |

---

## 5. 使用方法

### 1. CLI によるアニメーションデータのバッチ生成
特定のパラメータのシミュレーションを実行し、アニメーションファイルを直接生成・保存する場合：
```powershell
python vscode/simulation/kukei_ani.py --pitch-mm 1.50 --depth-mm 0.20 --width-mm 0.40 --output-dir "C:/path/to/save"
```

### 2. GUI（プレビュー画面）の起動
引数なし、または Tkinter を利用した設定画面からシミュレーションを実行したい場合：
```powershell
python vscode/simulation/kukei_ani.py
```
（※スクリプトがGUIを直接表示する仕様になっている場合、Tkinterウィンドウが表示され、手動でシミュレーションの進捗や応力変化を確認できます。）

---

## 6. 出力ファイル
*   **NPZ アニメーションデータ**:
    *   ファイル名例：`kukei_ani_pitch1500_depth200_width4000_psize700.npz`
    *   内部データ：全体領域の波面行列、拡大領域（きず周辺）の波面行列、空間のグリッド座標情報、およびプロット用のジオメトリ情報。
*   このファイルを `animation_player_for_npz.py` などの再生ツールで読み込むことで、高解像度の動画としていつでも伝搬の様子を観察できます。
