# sourse_new_2.py 使用説明書

`sourse_new_2.py` は、超音波の実験データ（CSV）およびシミュレーション結果（CSV）を読み込み、信号処理（切り出し、FFT）、正規化スペクトルの算出、および比較・可視化を行うための共通ライブラリです。

---

## 1. 概要

このライブラリは以下の機能を提供します。
- **データ読み込み**: 実験データおよびシミュレーションデータの自動探索と読み込み。
- **波形整形**: ピーク付近の自動切り出し（`kiritori2`）や時間軸の補間（シミュレーションデータを実験のサンプリングレートに合わせる）。
- **スペクトル解析**: ゼロパディング付き FFT による振幅スペクトルの算出。
- **正規化**: 平滑面（Smooth）のデータを参照とした正規化スペクトルの計算。
- **可視化**: 複数条件のスペクトルを重ね書きしたグラフの作成と EPS 形式での保存。

---

## 3. 基本的な使い方

### 実験データのスペクトルをプロットする
最も標準的な使い方は、`select_pitch_and_image_exp` 関数を呼び出すことです。

```python
# 例: ピッチ 2.00mm (コード 200) の試験体で、深さ 0.1mm, 0.15mm, 0.2mm のデータを比較
select_pitch_and_image_exp(200, [10, 15, 20])
```
- 第1引数: `pitch` (整数コード)
- 第2引数: `depth_list` (整数または浮動小数のリスト)
- **出力**: 指定された `output_dir` に `exp_yfs_200.eps` が保存され、画面にグラフが表示されます。

## 4. データ構造と命名規則

このライブラリは以下のフォルダ構造を前提としています。

### フォルダ構成
- `Experiment_Data/<Shape>/<pitch>_<depth>/*.csv`
- `Simulation_Data/<Shape>/<shape>_cupy_pitch<p>_depth<d>.csv`
- `Simulation_Data/Smooth/smooth_cupy_pitch125_depth0.csv` (参照用)

### パラメータ規則
`pitch` と `depth` は、実際の寸法[mm]を100倍した整数値（または一部小数）で管理されます。
- **Pitch**: `125` → 1.25 mm, `200` → 2.00 mm
- **Depth**: `10` → 0.10 mm, `20` → 0.20 mm

## 5. 主要な関数

| 関数名 | 内容 |
| :--- | :--- |
| `kiritori2(data, left, right)` | ピーク位置を基準に前後を切り出します。 |
| `make_fftdata(data, dt)` | ゼロパディングを行い、正規化された振幅スペクトルを返します。 |
| `import_data(pitch, depth)` | 実験用 CSV を読み込み、バイアス除去と平均化処理を行います。 |
| `interpolate_sim(data)` | シミュレーションの時間刻みを実験用 (`exp_dt = 0.5 ns`) に補間します。 |
| `select_pitch_and_image_exp` | **メイン関数。** 実験データをプロットし保存します。 |
| `calculate_rmse_with_frequency_band` | 実験とシミュレーションのスペクトルの一致度（RMSE）を計算します。 |

---

## 6. 注意事項

- **サンプリング間隔**: 実験データは `0.5 ns` (`0.0005e-06 s`) を固定値として使用しています。
- **FFT点数**: `fft_N = 2**14` (16384点) でゼロパディングされます。
- **周波数帯域**: 多くの関数で、正規化や評価の対象を `2MHz 〜 8MHz` の範囲に限定しています。
- **シミュレーション時間軸**: シミュレーションデータの切り出し開始位置（`sim_a1` 等）は、データの特性に合わせて調整が必要な場合があります。
