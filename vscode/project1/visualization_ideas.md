# 境界面におけるモード変換の可視化アイデア提案 (Visualization Strategy for Mode Conversion)

超音波が自由境界面や矩形溝の角部に衝突する際、縦波（P波）から横波（S波）やレイリー波（表面波）へのモード変換（あるいはその逆）が発生します。
シミュレーション上の応力および速度成分から、これらを効果的に可視化・分析するための4つのアプローチを提案します。

---

## 1. 物理量の分離による P波・S波の個別可視化 (Wave Field Separation)

現在のシミュレーション（[kukei_ani.py](file:///Users/hottayuki/Library/CloudStorage/GoogleDrive-callas47y@gmail.com/その他のパソコン/マイ コンピュータ/lab/vscode/project1/kukei_ani.py)）では応力成分 $T_1, T_3, T_5$ をそれぞれ個別に表示していますが、これらを物理的な意味に基づいて「体積変化（縦波）」と「せん断・回転（横波）」に分離することで、モード変換の瞬間が格段に捉えやすくなります。

*   **P波（縦波成分）の可視化指標**
    *   **静水圧（平均垂直応力）**: $P_{hydro} = \frac{T_1 + T_3}{2}$
    *   **速度場の発散（Divergence）**: $\nabla \cdot \mathbf{u} = \frac{\partial u_x}{\partial x} + \frac{\partial u_z}{\partial z}$
*   **S波（横波成分）の可視化指標**
    *   **せん断応力**: $T_5$
    *   **速度場の回転（Curl / 渦度）**: $(\nabla \times \mathbf{u})_y = \frac{\partial u_z}{\partial x} - \frac{\partial u_x}{\partial z}$

### 可視化の工夫 (Overlay Plotting)
P波の指標を **赤（Red）**、S波の指標を **青（Blue）**（あるいは異なるカラーマップ）に割り当て、半透明または合成（RGB合成）して一つの2D画像上にオーバーレイ表示します。
これにより、入射した赤い波（P波）が境界で反射した際に、青い波（S波）が尾を引くように発生する様子がひと目でわかります。

## 2. 時空間クロスセクションプロット (Space-Time B-scan)

2Dアニメーションは全体の伝搬を追うのには適していますが、波同士の干渉や正確な速度変化を定量的に追うことが困難です。そこで、特定のラインにおける時間的推移を1枚の画像に落とし込みます。

*   **手法**
    1.  境界面のすぐ下（例：$x = 0$ または $x = d_{depth} + \Delta x$ など、溝の底のライン）の水平格子点を選択します。
    2.  そのライン上の特定物理量（例：$T_5$ や $(T_1+T_3)/2$）を全時間ステップにわたってサンプリングします。
    3.  横軸を **空間座標 $z$**、縦軸を **時間 $t$** とした2次元カラーマップ（$z$-$t$ プロット）を描画します。

```
時間 t
  ▲
  │       \         / (縦波: 傾きが急)
  │        \       /
  │         \     /
  │ 衝突点   \   /
  │──★───────\─/────── (境界面・溝の角)
  │  │         \
  │  │          \ (レイリー波/横波: 傾きが緩やか)
  │  │           \
  └───────────────────► 空間座標 z
```

*   **メリット**
    *   波の軌跡が「直線」として現れます。直線の傾きの逆数が波の伝搬速度に対応します。
    *   縦波（高速 $c_L$）、横波（中速 $c_T$）、レイリー波（低速 $c_R$）で傾きが異なるため、衝突点（★）からどのような速度の波がどのような割合で発生・分岐したかが定量的に確認できます。

## 3. 粒子軌跡解析 (Hodogram / Lissajous)

粒子（格子点）の運動軌跡を描くことで、その領域を通過している波の「偏波特性（偏光）」を判定します。

*   **手法**
    *   境界面付近のいくつかの特徴的な点（きずの角部、境界面直下、バルク内など）を観測点として選定します。
    *   各点における速度成分 $u_x(t)$ と $u_z(t)$ を、時間を媒介変数として2次元平面上にプロットします（リサジュー図形）。
*   **波の同定方法**
    *   **直線軌道 (Linear)**: 伝搬方向と平行ならP波、直交する方向ならS波。
    *   **楕円軌道 (Elliptical)**: 境界面を伝わるレイリー波特有の挙動（反時計回りまたは時計回りの楕円運動）。

---

## 4. エネルギー流束（ポインティングベクトル）の可視化

応力と速度の積から、単位時間あたりにエネルギーがどの方向に流れているかを示すベクトル場 $\mathbf{P}$ を計算します。

$$\mathbf{P} = -\boldsymbol{\sigma} \cdot \mathbf{u}$$

$$P_x = -(T_1 u_x + T_5 u_z)$$
$$P_z = -(T_5 u_x + T_3 u_z)$$

*   **手法**
    *   各時間ステップにおいて、ベクトル $(P_x, P_z)$ を計算します。
    *   これを矢印（Quiver）や流線（Streamline）として表示します。
*   **メリット**
    *   波の位相情報に惑わされることなく、純粋に「エネルギーが境界の角をどのように回り込んで伝わっていくか」が流体のように視覚化されます。
