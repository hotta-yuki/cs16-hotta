# 周期的粗面・超音波探傷 FDTD シミュレーション プログラム構成と用途説明

本ディレクトリ (`vscode/project3_2026_09_17`) には、周期的粗面/欠陥（きず）における超音波探傷試験 (UT) の 2次元/3次元 弾性波動 FDTD シミュレーション、自動ループ処理、信号解析、および可視化のための主要プログラムが格納されています。

---

## 📄 各ファイルの用途一覧

| ファイル名 | 用途区分 | 概要・詳細な機能 |
| :--- | :--- | :--- |
| **`UT_FlawVariation_Sim.py`** | 2D FDTD シミュレーション | CuPy (GPU) を使用した 2次元弾性波動 FDTD 計算エンジン。欠陥のパラメータ（幅 $w$, 深さ $d$, ピッチ $p$）を入力として音場・応力場を計算し、探触子位置での時間領域反射波形データを保存します。 |
| **`loop_UT_sim.py`** | 自動ループ実行 | `simdata.csv` から欠陥パラメータ一覧を読み込み、`UT_FlawVariation_Sim.py` の計算処理を自動でバッチ実行します。大量の欠陥条件データを一括生成する際に利用します。 |
| **`simdata.csv`** | 設定ファイル | `loop_UT_sim.py` でバッチ処理を行うための欠陥形状パラメータリスト（`width`, `pitch`, `depth`）です。 |
| **`sourse_new_2.py`** | 信号処理・描画ライブラリ | 時間領域エコー波形の FFT 解析、平滑面反射波によるスペクトル正規化 ($\tilde{S}(f)$)、フィルタリング、波形/スペクトルプロットを作成する基盤共通ライブラリです。 |
| **`kukei_ani.py`** | 波動場可視化 | FDTD シミュレーション実行中の音場・応力場 ($T_1, T_3, T_5$) や粒子速度の二次元分布の波動伝搬アニメーション (GIF/MP4/HTML) および Bスキャン画像を生成・出力します。 |
| **`extract_features.py`** | 特徴量自動抽出 | 計算された反射波形および正規化スペクトルから、メイン波とテール波の振幅比 $A = A_{\text{tail}} / A_{\text{main}}$ や、音響ウッド異常によるディップ周波数 $f_{\text{Wood}}$、減衰量などの特徴量を自動抽出します。 |
| **`plot_simdata_compare.py`** | データ比較描画 | 異なる欠陥形状条件（幅や深さの違い）のシミュレーション波形や FFT スペクトルを重ね合わせてプロットし、比較・妥当性検証を行うスクリプトです。 |
| **`UT_FlawVariation_Sim_3d.py`** | 3D FDTD シミュレーション | 3次元弾性波動 FDTD モデルへの拡張用スクリプト。3次元的な空間における波動伝搬や音場の広がりを計算する際に使用します。 |

---

## 🚀 実行・利用の流れの例

### 1. 単体パラメータでの 2D シミュレーション実行
```bash
python UT_FlawVariation_Sim.py
```
* **入力**: スクリプト内の `x_length`, `y_length`, 欠陥寸法パラメータ
* **出力**: 計算された時間領域反射波形 CSV / NPZ ファイル

### 2. 条件を変えた自動バッチシミュレーション
```bash
python loop_UT_sim.py
```
* `simdata.csv` 内のリストに従って複数の欠陥形状について連続計算を行い、結果を指定の出力フォルダに自動保存します。

### 3. 波形解析とプロット（ライブラリ利用）
`sourse_new_2.py` をモジュールとしてインポートし、波形の FFT や正規化スペクトルのプロットを行います。

# 例: 波形の読み込み、FFT、正規化プロット

## 💡 物理的・力学的背景メモ
* **$T_1$ ($\sigma_{xx}$)**: $x$ 方向垂直応力（主に縦波バルク波に対応）
* **$T_3$ ($\sigma_{zz}$)**: $z$ 方向垂直応力（粗面境界に沿う表面波/レイリー波に対応）
* **$T_5$ ($\sigma_{xz}$)**: せん断応力（欠陥角部での L波 $\rightleftharpoons$ SV波・レイリー波のモード変換を媒介）
