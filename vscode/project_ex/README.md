# 3D自然散歩ゲーム 要件定義書

ゼルダの伝説のように、自然豊かな3Dマップを静かに散歩するゲームの要件定義書です。

## 1. ゲーム概要
- **コンセプト**: 戦闘や目的から解放され、美しい自然（木々、草花、川など）の中を一人で静かに歩き回る体験を提供する3Dゲーム。
- **ターゲット環境**: 
  1. 一次開発：Webブラウザで動作するWebアプリ（HTML5 / Three.js など）
  2. 二次開発：Webアプリをベースにした、PC（Windows等）で動くデスクトップアプリ（Electron や Tauri などによるパッケージングを想定）

---

## 2. コア要件（確定）
- **グラフィック**: 3D空間
- **ゲーム性**: 戦闘要素なし。敵や障害物は一切配置しない。
- **世界観**: モブ（町の人）や動物などの生命体は登場せず、プレイヤーが一人きりで自然を探索する。

---

## 3. 詳細仕様

### 3.1. カメラ視点（操作感）
- **一人称視点 (FPS)**: プレイヤー自身の目線で周りを見渡す仕様（没入感を最優先）。カメラ方向への移動とマウスによる視点変更。

### 3.2. 地形と自然環境
- **青空と緑の草原**: 澄み渡る美しい青空と、明るく照らされた自然豊かな草原。
- **自然の要素**: なだらかな起伏のある鮮やかな緑の草原、風に揺れる草、ランダムに配置された木、湖、湖畔の岩々、丘の上の神秘的なモニュメント。
- **オブジェクト構成**:
  - **木 (Trees)**: 広葉樹（もこもこ葉と曲がった幹）と針葉樹（傘重ね）の2種類、計45本をランダム配置（当たり判定あり）。
  - **湖 (Lake)**: 地形がすり鉢状に窪み、美しい青色の水面（半透明）が広がる。湖に入ると自動的に水面に浮き、水面を漂う（泳ぐ）ような挙動になる。
  - **岩 (Rocks)**: 風化したグレーの岩石を、湖の周囲（湖畔）や草原に計24個配置（当たり判定あり）。
  - **モニュメント (Monument)**: 北西の丘の上に位置する古代遺跡。石の台座と壊れた4本の石柱、中心で発光・回転する神秘的な巨大結晶を配置（当たり判定あり）。

### 3.3. 環境の変化（時間・天候）
- **時間・天候の固定**: 天候や時間の動的な変化は一旦「なし」とし、常に明るい「昼（青空）」で固定。

### 3.4. 操作方法
- 移動: キーボード（WASD / 矢印キーで移動）
- 視点変更: マウス移動
- ジャンプ: Spaceキー
- BGMミュート切替: Mキー（散歩中も可能）

### 3.5. 音響・BGM
- **ピアノBGM**: 心が落ち着く穏やかなピアノ音楽をBGMとして再生する。
- **効果音**: 環境音（風の音）や足音は一旦なしとする（今後の拡張項目）。
- **BGM設定の変更**: ポインターロックが外れている一時停止（エスケープ）画面のメニュー内、または散歩中に M キーを押すことでBGMのオン・オフを切り替えることができる。

## 4. 技術スタック
- **3D描画**: Three.js (WebGLライブラリ)
- **プロジェクト構成・ビルドツール**: Vite を使用したフロントエンド構成。
