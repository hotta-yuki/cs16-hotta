# antigravity_log — Antigravity の AI 利用記録（手動）

このディレクトリには **Antigravity の利用記録を手動で** 残します。
`update_history.ps1` を実行すると、ここの `YYYYMMDD.md` が
`進捗報告/gemini_log/YYYYMMDD.md` の「Antigravity」セクションへ自動で取り込まれます。

## なぜ手動なのか

Gemini CLI と Claude Code はローカルに会話ログ（JSONL）を残すため自動で取り込めますが、
Antigravity は会話の全文をローカルに保存しません。`state.vscdb` に入っているのは
base64 でエンコードされたタイトルの要約だけで、しかも同じデータベースに OAuth トークンが
含まれるため、機械的に解析する方法は取っていません。

## 書き方

当日の日付のファイル（例 `20260917.md`）に追記してください。このファイル自身（README.md）は
`YYYYMMDD.md` の形式ではないので取り込まれません。

```markdown
## 週次レポート 20260917 の本文執筆

- **利用目的**: 進捗報告の「CuPy の環境構築」節の日本語執筆
- **入力の要約**: HANDOFF.md の 2026-09-17 エントリ（GPU 名、計算時間の実測値）を渡した
- **出力の要約**: 環境構築の経緯と実測値をまとめた本文を約400字で生成
- **ファクトチェック**: 計算時間は Claude Code 側の実測ログと照合。GPU 名は nvidia-smi の出力と一致を確認
- **成果物への反映**: 生成文をそのまま採用せず、研究室の文体に合わせて自分で書き直した
```

項目は `Gemini.md` 2章「記録項目」に対応しています。埋められないものは「該当なし」と明記してください。
