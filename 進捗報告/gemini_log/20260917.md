> ### 2. `.git` に 2.7GB のゴミが残っている
> 
> ```
> in-pack: 2246 objects / size-pack: 2.79 GiB
> 到達可能オブジェクト: 810 / 2246
> ```
> 
> 履歴から到達できない巨大 blob が残っています（**1085MB / 1058MB / 704MB / 578MB / 121MB / 100MB**）。reflog を見ると 2026-07-10 の `reset: moving to HEAD` が痕跡で、大きなファイルを `git add` して reset した際の残骸です。
> 
> ```powershell
> git reflog expire --expire-unreachable=now --all
> git gc --prune=now
> ```
> 
> で大半を回収でき、おそらく 2.8GB → 数十MB になります。**到達不能オブジェクトが完全に消える不可逆操作**なので、実行はご判断ください（実際のコミット履歴と現在のファイルは一切失われません）。
